# 🌍 AI-Powered Travel Chatbot

An interactive web-based travel assistant application developed using Python, Streamlit, and SQLite to help users explore travel packages, calculate pricing, and receive tailored recommendations.

## 🚀 Features
* **Interactive Chat Interface:** Built with Streamlit for a seamless and responsive user experience.
* **Smart Matching Algorithms:** Implements **Levenshtein distance fuzzy string matching** to handle user typos and query variations effectively.
* **NLP Sentiment Analysis:** Analyzes user inputs and preferences to gauge sentiment and refine travel recommendations.
* **Dynamic Pricing Engine:** Automatically calculates package pricing based on custom user requirements.
* **SQLite Database:** Manages travel destinations, package details, and user interaction logs efficiently.

## 🛠️ Tech Stack
* **Language:** Python
* **Web Framework:** Streamlit
* **Database:** SQLite
* **Algorithms & Processing:** Levenshtein Distance, NLP Sentiment Analysis
